# imf-sampling
Code and synthetic datasets for my bachelor thesis: **Statistical Signatures of Stellar Initial Mass Function Sampling: From Star Clusters to Semi-Resolved Populations**. The thesis compares two approaches to sampling the stellar initial mass function: random sampling and optimal sampling. The analysis is based on synthetic star cluster populations.

The repository contains separate scripts for random and optimal sampling, and the notebooks correspond to the individual chapters of the thesis.

The aforementioned files are organized thematically into three folders: `code`, `data`, and `notebooks`.

## Notes

The optimal sampling implementation uses the publicly available GalIMF code. The path to the GalIMF file may need to be adjusted locally.

All datasets are synthetic and were generated for the purposes of the thesis.
