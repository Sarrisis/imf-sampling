# Code

This folder contains Python scripts used to generate synthetic stellar populations and machine learning datasets.

## Contents

- `Simulated_clusters_ran.py` — implementation of random sampling.
- `Simulated_clusters_opt.py` — implementation of optimal sampling based on GalIMF.
- `ML_dataset_balanced.py` — script used to create the balanced 1:1 machine learning dataset.
- `ML_dataset_unbalanced.py` — script used to create the unbalanced 1:20 machine learning dataset.

The scripts were used to generate the synthetic datasets analyzed in the thesis.
